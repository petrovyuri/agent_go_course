Карта документации Eino

Эта страница собирает всю официальную документацию Eino, которая пригодится по ходу курса, и раскладывает её по модулям. Каждая ссылка идёт с короткой подписью, куда она ведёт. Держите страницу под рукой как справочник: те же ссылки продублированы в конце соответствующих уроков.

Вся документация живёт на сайте cloudwego.io/docs/eino. Часть страниц про конкретные интеграции (Ollama, MCP, LangFuse) ведёт дальше на README компонента в репозитории eino-ext.

Модуль 1. Введение

  • Обзор Eino: зачем нужен фреймворк и из чего он состоит.
  • Graph или Agent: когда брать граф, а когда готового агента.
  • Eino: open-source обзор: история, цели и экосистема проекта.
  • Quick Start: серия глав от первого вызова модели до полноценного агента.
  • ChatModel и Message: первый чат и формат сообщений.
  • Интеграции чат-моделей: список поддержанных моделей, включая Ollama.
  • Ядро Eino: карта трёх слоёв (компоненты, оркестрация, аспекты).

Модуль 2. Eino Core

  • ChatModel и Message: роли System / User / Assistant / Tool.
  • Компонент ChatModel: интерфейс Generate и Stream, реализации, структурированный вывод.
  • Опции вызова: температура, top-p, лимиты токенов и другие параметры.
  • Стриминг в Eino: чтение и склейка чанков ответа.
  • Шаблоны промптов: FString, GoTemplate и Jinja2.

Модуль 3. Оркестрация

  • Принципы оркестрации: типобезопасность, потоки данных, обработка ошибок.
  • Chain и Graph: введение: узлы, рёбра, ветвление, START и END.
  • Lambda-узлы: вставка произвольной Go-логики в граф.
  • Workflow: параллельные ветви и слияние данных.
  • Плагин EinoDev: установка: подключение плагина к IDE.
  • EinoDev: визуальная сборка графа: просмотр и отладка графа.

Модуль 4. Mini Code: каркас агента

  • Обзор Eino: общая картина перед стартом проекта.
  • Chain и Graph: введение: на этом строится граф разговора Mini Code.
  • EinoDev: визуальная сборка графа: смотрим граф Mini Code в плагине.

Модуль 5. Инструменты и tool-calling

  • ToolsNode: узел исполнения инструментов в графе.
  • Как создать инструмент: tool.Info, InvokableTool, схема параметров.
  • Инструменты и файловая система: связка модели с инструментами на практике.

Модуль 6. Mini Code: работа с файлами

  • Как создать инструмент: основа для read_file, list_dir и grep.
  • Инструменты и файловая система: модель сама выбирает нужный инструмент.

Модуль 7. ReAct

  • ReAct Agent: готовый агент, конфигурация, запуск, лимит шагов.
  • Chain и Graph: введение: как собрать ReAct-цикл из графа вручную.
  • Стриминг в Eino: потоковый вывод внутри ReAct-агента.

Модуль 8. Mini Code: думающий агент

  • ReAct Agent: превращаем линейный вызов Mini Code в настоящий цикл.

Модуль 9. Состояние, память и надёжность

  • Checkpoints и interrupt: состояние графа, сохранение и восстановление прогресса.
  • Память и сессия: история диалога, которая живёт между запусками.
  • Interrupt / Resume: human-in-the-loop, пауза и продолжение работы.
  • TurnLoop: таймауты, отмена и прерывание хода агента.
  • Принципы оркестрации: обработка ошибок узлов.

Модуль 10. Mini Code: память, правка, подтверждения

  • Память и сессия: память диалога для Mini Code.
  • Инструменты и файловая система: write_file, edit_file и запуск команд.
  • Interrupt / Resume: подтверждение перед записью файла и командой.
  • Checkpoints и interrupt: продолжить сессию после перезапуска.

Модуль 11. RAG и MCP

  • Embedding: векторизация текста.
  • Indexer: запись документов в векторное хранилище.
  • Retriever: поиск релевантных документов для RAG.
  • Chain и Graph: введение: сборка RAG-графа retrieve, prompt, generate.
  • ReAct Agent: агентный RAG.
  • Инструменты экосистемы: подключение MCP-серверов как инструментов.

Модуль 12. Mini Code: знание проекта

  • Indexer: индексация кодовой базы проекта.
  • Интеграции эмбеддингов: эмбеддинги через Ollama.
  • Retriever: поиск релевантных файлов перед ответом.
  • ReAct Agent: RAG внутри агента.
  • Инструменты экосистемы: filesystem и git-серверы по MCP.

Модуль 13. Наблюдаемость (LangFuse)

  • Callbacks: руководство: OnStart, OnEnd, OnError для отладки.
  • Интеграции callbacks: подключение LangFuse.
  • Callbacks и трейсинг: наблюдаемость агента и чтение трейсов.

Модуль 14. Mini Code: финал и прод-готовность

  • Callbacks и трейсинг: трейсинг Mini Code через LangFuse.
  • Мульти-агентные системы: куда расти дальше после курса.

Полировка CLI и терминальный интерфейс Mini Code (флаги, Bubble Tea) к Eino напрямую не относятся, поэтому профильной страницы в документации для них нет.
